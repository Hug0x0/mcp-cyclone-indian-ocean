# Data Sources

This MCP favors official sources and keeps secondary impact sources clearly labeled.

Primary sources:

- RSMC La Réunion / Météo-France tropical cyclone centre: official WMO Regional Specialized Meteorological Centre for the South-West Indian Ocean.
- Météo-France La Réunion cyclone page: public local cyclone information.
- Météo-France vigilance pages for La Réunion and Mayotte.

Secondary source:

- GDACS tropical cyclones for global disaster-alert and impact context.

Important limitation: this MCP is not an emergency-warning authority. During active cyclone events, users must follow prefecture, civil-protection, and Météo-France instructions.
